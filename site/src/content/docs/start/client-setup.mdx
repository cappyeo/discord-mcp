discord-mcp speaks **stdio MCP** and works with any client that can spawn an MCP server
as a subprocess. The `init` command generates the right `mcpServers` snippet for the
client you select; it prints that snippet by default, so you stay in control of the
file you merge it into.

<Aside type="caution">
`init` does not discover or edit your client config automatically. In an interactive terminal,
enter the token when prompted so it is not stored in shell history. If you leave it empty, the
snippet contains the literal `${env:DISCORD_TOKEN}` placeholder. Replace it in the local config
unless you have verified that your client expands environment placeholders.
</Aside>

## Choose your client

<ClientTabs>
  <div slot="claude-desktop">

  ```bash
  discord-mcp init --client claude-desktop
  ```

  Merge the printed `discord-mcp` entry into the `mcpServers` object, then fully quit
  and reopen Claude Desktop.

  | OS | Config file |
  | -- | ----------- |
  | macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
  | Windows | `%APPDATA%\Claude\claude_desktop_config.json` |
  | Linux | `~/.config/Claude/claude_desktop_config.json` |

  </div>
  <div slot="claude-code">

  ```bash
  discord-mcp init --client claude-code
  ```

  Merge the output into `~/.claude.json` for user-level configuration, or into
  `<project>/.mcp.json` for a project. Claude Code also supports its managed
  `claude mcp add` workflow; use the generated snippet when you prefer explicit JSON.

  </div>
  <div slot="cursor">

  ```bash
  discord-mcp init --client cursor
  ```

  Merge the output into `~/.cursor/mcp.json` for global access or
  `<project>/.cursor/mcp.json` for one project. Restart Cursor after changing it.

  </div>
  <div slot="generic">

  ```bash
  discord-mcp init --client generic
  ```

  The output is a standard `mcpServers` block. Place it where your MCP client's own
  documentation expects stdio server configuration.

  </div>
</ClientTabs>

The generated snippet uses the current CLI path, so it works immediately from the
installation that created it. If you later move or replace that installation, generate
a fresh snippet instead of editing an absolute path by hand.

Once the snippet contains a real token, treat the whole client config as a secret: do not
commit, share, or screenshot it.

## Verifying the connection

After merging config and restarting your client, set a temporary token for the shell
where you run diagnostics:

```bash
export DISCORD_TOKEN="YOUR.TOKEN.HERE"          # macOS / Linux
```

```powershell
$env:DISCORD_TOKEN = "YOUR.TOKEN.HERE"          # Windows PowerShell
```

Then run:

```bash
discord-mcp doctor --online
```

If your client's logs show successful `tools/list` responses, the wiring is correct.
