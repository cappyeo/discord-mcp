discord-mcp is a local stdio MCP server that lets an AI client call Discord through a bot you
control. Nothing is hosted for you: your client starts the process, passes the bot token in its
environment, and receives structured tool results over MCP.

<Aside type="caution">
The server inherits the bot's Discord permissions. Some ordinary write tools execute on the
first call, so begin in a private test server and use least-privilege bot permissions.
</Aside>

## What you will set up

This tutorial leads to one safe, repeatable outcome: a local MCP client can
start `discord-mcp`, make a read-only Discord request, and send one test message
inside a private server you control.

<Steps>

1. [Create a Discord bot](/discord-mcp/start/create-discord-bot/) and install it in a test server.
2. [Install the CLI](/discord-mcp/start/installation/) with Node.js 22.12 or newer.
3. [Connect your MCP client](/discord-mcp/start/client-setup/) using a generated config snippet.
4. Run `discord-mcp doctor --online`, then inspect the request and result contracts in [How a tool call works](/discord-mcp/start/first-tool-call/).

</Steps>

When you finish, use [Tools](/discord-mcp/tools/) for exact contracts or
[Workflows](/discord-mcp/recipes/) for multi-step tasks.
