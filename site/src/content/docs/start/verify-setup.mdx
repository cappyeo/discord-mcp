This unit proves the full path from your MCP client to Discord. You will authenticate the
bot, make a read-only request, discover a channel ID, and send one deliberate test message.

## Where are you going?

The quickstart begins with diagnostics and `users_get_current`, so you can verify the client
and token without changing Discord. It then uses `channels_list` to obtain a real ID before
calling `messages_send` in your private test channel.

The final lesson explains the request, validation, execution, and structured result so you
can recognize the same flow in every tool reference.
