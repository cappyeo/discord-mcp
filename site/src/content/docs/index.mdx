## Get connected

Install the CLI once, then generate the configuration for the AI client you already use.

<ClientTabs>
  <div slot="claude-desktop">

  ```bash
  npm install -g @discord-mcp/cli
  discord-mcp init --client claude-desktop
  ```

  </div>
  <div slot="claude-code">

  ```bash
  npm install -g @discord-mcp/cli
  discord-mcp init --client claude-code
  ```

  </div>
  <div slot="cursor">

  ```bash
  npm install -g @discord-mcp/cli
  discord-mcp init --client cursor
  ```

  </div>
  <div slot="generic">

  ```bash
  npm install -g @discord-mcp/cli
  discord-mcp init --client generic
  ```

  </div>
</ClientTabs>

`init` prints a complete configuration snippet without overwriting your files. Merge it into your client configuration, set `DISCORD_TOKEN`, then run `discord-mcp doctor --online` to validate the connection. See the [full installation guide](/discord-mcp/start/installation/) for token and platform-specific details.
