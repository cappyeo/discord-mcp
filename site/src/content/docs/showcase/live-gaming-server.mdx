## What the walkthrough demonstrates

- Starting from a default Discord guild rather than a prepared mockup.
- Building the channel tree, role system, permissions, and staff space through
  typed MCP tools.
- Enabling Community, Welcome Screen, Advanced Onboarding, and AutoMod.
- Sending and pinning validated Components V2 welcome and guide cards.
- Reading the final Discord state back to confirm the resulting structure.

The recording uses a disposable test server and contains no bot credential.
The final visual result is one example configuration; real deployments should
still use a caller-owned bot with least-privilege Discord roles and narrow
guild/category allowlists.

<Aside type="note">
The demo is evidence of an end-to-end interactive workflow, not a universal
speed or cost benchmark. Model, client, Discord rate limits, and server design
all affect a real run.
</Aside>
